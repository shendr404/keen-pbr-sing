В keen-pbr-sing можно добавлять узлы sing-box прямо через веб-интерфейс и направлять выбранный трафик Keenetic в TUN-интерфейс.

## Подключение

1. Установите и запустите sing-box с TUN-интерфейсом (по умолчанию `sbtun`).
2. Откройте **Sing-box** в веб-интерфейсе keen-pbr.
3. Вставьте ссылку `vless://`, `hysteria2://`, `trojan://`, `ss://` или `vmess://` и проверьте предварительный просмотр.
4. Добавьте узел и выберите его для подключения.
5. Настройте правило маршрутизации с outbound типа `interface` для `sbtun`. Для TUN шлюз должен быть `auto`.

## Подписки и автообновление

Добавьте URL подписки. Поддерживаются текстовые и base64-списки ссылок, JSON sing-box и Clash. Ручные узлы сохраняются при обновлении подписки.

Интервал задаётся **в часах**. Значение `0` отключает автоматическое обновление. Демон проверяет срок раз в 30 секунд и обновляет подписки независимо от открытого браузера. Загрузка ограничена 2 МиБ и таймаутом 20 секунд; после неудачи следующая попытка выполняется через пять минут. Одновременно обновляется не более одной подписки.

Для ручного обновления из SSH:

```sh
/opt/usr/bin/keen-pbr subscriptions refresh --all
# Или отдельную подписку:
/opt/usr/bin/keen-pbr subscriptions refresh <id>
```

## Безопасность и восстановление

Ссылки хранятся в `/opt/etc/keen-pbr/sing-box-links.json`, конфигурация sing-box — в `/opt/etc/sing-box/config.json`. Перед изменениями делается резервная копия, выполняется `sing-box check`; при ошибке прежняя конфигурация восстанавливается. Секретные части ссылок не выводятся в список профилей.

После настройки проверьте маршрут и счётчики трафика outbound на странице обзора.
